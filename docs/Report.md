# Отчёт по итогам тестирования

## Краткое описание

Проведено автоматизированное тестирование комплексного веб-сервиса по покупке туров **«Путешествие дня»** (`aqa-shop.jar`). Проверены сценарии оплаты тура по дебетовой карте: работа пользовательского интерфейса, валидация полей формы («Номер карты», «Месяц», «Год», «Владелец», «CVC/CVV»), отображение системных уведомлений при одобрении и отклонении платежа, а также корректность записи статусов операций (`APPROVED` / `DECLINED`) в СУБД MySQL 8.0.

## Количество тест-кейсов и статистика прогона

Всего автоматизировано и выполнено **15 тест-кейсов** (класс `PaymentFormTest`):
* **Успешных (Passed):** 11 (80%)
* **Неуспешных (Failed):** 4 (20%) — падение тестов обусловлено выявленными дефектами в работе приложения.

## Общие рекомендации

1. **Обработка ответов банковского сервиса:** привести поведение пользовательского интерфейса в соответствие с фактическим статусом транзакции — при получении статуса `DECLINED` отображать уведомление об отказе в проведении операции.
2. **Валидация поля «Месяц»:** ограничить допустимый диапазон ввода значениями от `01` до `12`, исключив значение `00`.
3. **Валидация поля «Владелец»:** настроить проверку вводимых данных на соответствие формату имени и фамилии на латинице (разрешить только буквы латинского алфавита, пробел и дефис, запретив цифры и спецсимволы).
